求职小贴士

  • 招聘时间线：2027 届秋招进行中：深航民航大学站 9/12 截止（其他站点 9/18、郑州航院站 10/22 宣讲）、厦门太古 BM 培训生（本科）9/12 截止、春秋校招批次 9/20 截止（以官网为准）、华夏 9/26 截止（部分院校页标注 10/31，以官网为准）、南航网申 9/1-10/31、海航官网岗 10/30 截止、东航技术 12/31 截止；厦航/吉祥/顺丰等简章已发布，珠海摩天宇校招已启动（9/6 民航大学宣讲），社招常年开放，可随时关注。
  • 硬条件自查：机务岗位普遍要求无色盲色弱、无恐高，多数公司入职体检会查；英语四级（大专英语 A 级 / 公共三级）是常见门槛。
  • 执照：CAAC CCAR-66 维修执照（基础部分 + 机型签署）。校招入职后公司一般会安排培训考取；社招很多岗位直接要求持照。
  • 投递材料：简历（带照片）、成绩单、英语证书、实习证明、身份证件提前扫描成 PDF，官网网申和宣讲会现场都会用到。
  • 新加坡岗位：注意工作签证（EP/SP）、英语要求；应届生可优先看 SIAEC 的培训生项目（AMLT / Dual Trade）。
  • 工作地点：机务岗位集中在广州、深圳、北京、上海、成都、海口、济南、厦门、珠海、新加坡等地，可先圈定意向城市再投。
这个网站怎么更新招聘信息？

所有岗位数据都放在 data.js 一个文件里，更新方法：

  1. 用记事本或任意编辑器打开 data.js；
  2. 找到 positions 数组，复制任意一个 { ... } 条目，修改公司、岗位、要求、链接、日期；
  3. 保存文件，刷新网页即可看到更新。

也可以直接把新招聘信息发给 Codex，由它帮你更新到 data.js。
