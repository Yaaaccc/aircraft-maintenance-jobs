# 机务维修招聘信息站

一个简洁的静态网页，聚合中国（大陆）与新加坡的航空公司、维修企业（如 GAMECO、Ameco、海航技术、山东太古、HAECO 厦门太古、SIAEC 等）的机务维修工程师校招与社招信息。

## 文件结构

```
aircraft-maintenance-jobs/
├── index.html   # 页面结构
├── styles.css   # 样式（自适应手机/平板/电脑）
├── data.js      # ★ 所有招聘数据，更新岗位只改这个文件
├── app.js       # 筛选、搜索、渲染逻辑
└── README.md    # 本说明
```

## 本地预览

直接双击 `index.html` 即可在浏览器打开。也可以启动本地服务器：

```
python -m http.server 8000
```

然后访问 http://localhost:8000

## 如何更新招聘信息

1. 用记事本或 VSCode 打开 `data.js`；
2. 在 `positions` 数组里复制任意一个 `{ ... }` 条目，修改以下字段：
   - `company`：公司名称
   - `title`：岗位名称
   - `type`：`["校招"]`、`["社招"]` 或 `["实习"]`，可多个
   - `region`：`中国大陆` 或 `新加坡`
   - `locations`：工作地点
   - `updated`：信息更新日期（格式 `YYYY-MM-DD`）
   - `requirements`：任职要求（数组，每行一条）
   - `channels`：投递渠道（`label` 显示文字，`url` 链接；没有链接就留空字符串）
   - `note` / `source`：备注和来源链接（可选）
3. 保存文件，刷新网页即可。

也可以用相同方式维护下方 `portals` 数组（官方投递渠道目录）。

## 部署到公网（手机随时打开）

网站是纯静态文件，部署方式任选：

### GitHub Pages（推荐，免费）
1. 新建 GitHub 仓库，把 `aircraft-maintenance-jobs` 里的文件传到仓库根目录；
2. 仓库 Settings → Pages → Source 选 `main` 分支；
3. 几分钟后即可通过 `https://用户名.github.io/仓库名/` 访问。

### Vercel / Netlify（免费，拖拽即部署）
1. 注册账号后选择导入项目（或直接拖拽整个文件夹）；
2. 自动生成网址，手机浏览器直接打开。

### 国内访问
可用 Gitee Pages、腾讯云/阿里云静态网站托管、对象存储（OSS/COS）等，按平台文档上传文件夹即可。
